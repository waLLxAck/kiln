# Kiln 0.25.7

Remove the manual import controls for local skills and agents now that checked locations feed the library automatically.

- **Choose locations once.** Settings and setup keep the location checkboxes and explain automatic discovery, without a separate local import button or discovery dialog.
- **Start from the library.** The empty library points to location settings. Existing and new skills and agents appear as drafts, ready for review and approval.
- **Keep repository imports.** Importing from another local repository or GitHub, browsing skill repositories, and restoring library exports remain available.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
