# Kiln 0.16.0

Fetch just the collection and content you need:

```powershell
kiln collections list
kiln items list --collection "Game Design Practice"
kiln items list --collection "Game Design Practice" --query puzzles
kiln items read <id1> <id2> --full
```

- Exact collection filtering combines with search, status and pagination.
- Item lists return IDs, titles and kinds. **Scripts needing the previous metadata should add `--full`.**
- Collection summaries show names and counts, including empty collections.
- Read up to 100 selected IDs in one process. Single reads keep their existing response; batch reads return `{ items: [...] }` in requested order.
- Unknown, misplaced, repeated and valueless options fail clearly before opening storage.
- Search no longer truncates at 500 matches before filtering and pagination.
- `kiln --help` includes short examples. Both `kiln` and `workbench` are declared CLI names.

Lists include archived/rejected items and exclude trash. Collection names match exactly, including case. Use `nextOffset` for the next page. `items list --full` adds metadata; `items read --full` includes content and files. A failed batch returns no partial content.

Install the Windows setup executable, or use Kiln's **Prepare update → Restart to update** flow when this release is available in the configured local update folder.
