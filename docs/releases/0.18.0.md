# Kiln 0.18.0

The first open-source release: test on your own project, and a new look.

- **Test on your own project.** Experiments have a **Project / repository** selector. Pick an enrolled project, use **Choose project folder…** for any local repository or directory, or keep **No project — isolated example**. The selected folder becomes the working directory for Codex or Claude Code. Experiments stay read-only, so tasks that need edits or unavailable tools come back as uncertain. Runs show which project they used, and the last project is offered again for that item.
- **Retry repeats the exact run.** It reuses the same revision, project and context. **Manual handoff instead** keeps your project selection and tells you where to start the external session.
- **Only agent actions ask for consent.** Approving, installing, publishing and saving edits never call a model. Approval commits and revision notes use plain messages.
- **Install locations are in one place.** An item's install switches sit in their own **Install locations** section. For skills that are already installed, the main button opens their installed copies.
- **Imported skill repositories** file skills under `mine/<org>/` into a `My skills · <Org>` collection.
- **New logo** in the app, the installer and the website.

Kiln is now MIT-licensed open source at [github.com/waLLxAck/kiln](https://github.com/waLLxAck/kiln), with a website at [wallxack.github.io/kiln](https://wallxack.github.io/kiln/). Published installers are built with `KILN_PUBLIC_BUILD=1`. They record no build folder, so they don't watch for local builds. To update, download the newer installer from the releases page.

Windows builds remain unsigned, so SmartScreen may warn before the installer runs. The full Windows release matrix has not been certified.

Validation: the type check, production build and all 125 unit tests passed on Linux. The installer was built on a GitHub Actions Windows runner by `.github/workflows/release.yml`, after the type check and unit tests passed there too. The Electron desktop suite was not run for this release, and installing on a real Windows machine was not tested.
