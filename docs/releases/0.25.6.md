# Kiln 0.25.6

Skills and agent definitions in your managed folders now appear in the library automatically, ready to review and approve.

- **Skip the manual import.** Existing and new skills and agents in checked locations arrive as unapproved drafts, including their supporting files. Enable locations in **Settings → Skill & agent locations** to choose which folders Kiln discovers.
- **See new files as they arrive.** Folder watching updates the library after writes settle. Kiln also checks at startup, when you refresh the library, and once a minute as a fallback. Newly created folders and linked skills are supported.
- **Keep discovery lightweight.** Idle scans skip the contents of known bundles. Repeated scans deduplicate identical content and remember handled paths, so editing or deleting a library item does not recreate it from its original folder.
- **Keep control of your library.** Discovery leaves original files in place and adds no approvals. Existing library revisions stay intact; use **Keep these changes** to bring external edits into an existing item. **Inspect folders** still offers cleanup of empty folders and broken links.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
