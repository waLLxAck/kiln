# Kiln 0.25.9

Catch a machine up with one command.

- **`kiln sync`.** Fetches and pulls your library from GitHub, then installs everything this machine should have: the skills listed in `installs.json`, anything marked for this machine, and skills approved on any machine since this one last synced. Newly approved skills go into this machine's Claude and Agents folders and are added to `installs.json`, so your other machines pick them up too. A skill you removed from this machine is not brought back.
- **Local edits stay put.** Copies edited on this machine, or a different folder with the same name, are skipped and listed. `kiln sync --force` (or `-f`) moves them into Kiln's machine-private `replaced` folder and installs the approved revision.
- **Clearer sync results.** **Install everything marked for this machine** and `skills sync` now say a copy was skipped because it was edited here, rather than reporting a blocked deployment.
- **Offline or refused pulls.** If the fetch fails or the pull is refused (unsaved edits GitHub also changed), `kiln sync` says so and installs what the library already has.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
