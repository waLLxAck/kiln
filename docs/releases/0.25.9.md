# Kiln 0.25.9

Catch a machine up with one command.

- **`kiln sync`.** Fetches and pulls your library from GitHub, then installs everything this machine should have: the skills listed in `installs.json`, anything marked for this machine, and skills approved on any machine since this one last synced. A newly approved skill that nothing lists yet, and that Kiln never installed here, goes into this machine's Claude and Agents folders (whichever are set up) and is added to `installs.json` for both, so your other machines pick it up too. A skill you removed from this machine is not brought back by a new approval; it is reinstalled only if another machine lists it in `installs.json` again.
- **Local edits stay put.** Copies edited or deleted on this machine, links, and different folders with the same name are skipped and listed. `kiln sync --force` (or `-f`) moves them into Kiln's machine-private `replaced` folder and installs the approved revision.
- **Clearer sync results.** **Install everything marked for this machine** and `skills sync` now say a copy was skipped because it was edited here, rather than reporting a blocked deployment.
- **Offline or refused pulls.** If the fetch fails or the pull is refused (unsaved edits GitHub also changed), `kiln sync` says so and installs what the library already has.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
