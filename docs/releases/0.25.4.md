# Kiln 0.25.4

Fix PDF analysis when the agent cannot read attachments, and recover from YouTube’s “Sign in to confirm you’re not a bot” check when distilling a video.

- **Read PDFs directly.** Kiln extracts selectable PDF text before analysis and sends it to the agent with page numbers. Text attachments are included directly too, so file access restrictions no longer hide the source. This also applies when asking about a source or an entry derived from it.
- **Report unreadable PDFs.** Damaged, locked or scanned PDFs fail with recovery instructions instead of completing an analysis without the book. Originals stay attached. Scanned PDFs need OCR first; documents over 1,000 pages or 500,000 extracted characters need splitting.
- **Choose a browser for YouTube cookies.** In Settings → YouTube, select the browser where you opened the video and completed verification. Save the setting, then retry distillation.
- **Use the right profile.** Enter a profile name or folder path if you use multiple browser profiles. Leave it blank to use the most recently used profile. The browser and profile choice stay on this machine.
- **Clear recovery instructions.** When YouTube blocks a request, Kiln explains how to complete verification and retry. Exported `cookies.txt` files in your home folder remain supported when “No browser” is selected.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
