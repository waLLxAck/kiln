# Kiln 0.25.3

Restore the update shortcut in the bottom-left corner, beside the installed version.

- **Updates back in the sidebar.** When a new version is available, the download icon is at the foot of the left sidebar again. It stays visible while the navigation and collections scroll.
- **Download, then restart when ready.** Follow download progress in the same place and choose Restart to apply the prepared update. Kiln stays open while you keep working.
- **Release-page downloads stay available.** Copies that cannot install themselves, including macOS and Linux tar.gz builds, open the new version’s release page from the sidebar shortcut.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
