# Kiln 0.25.1

A performance release: screens that kept loading, freezes after starring or approving an item, and the pause after a run finished are fixed. The [user guide](../GUIDE.md) is unchanged apart from small notes.

- **Nothing spins forever.** An item, page or dialog that can't load now says why, with **Retry** (and **Back to library** on an item). After a few seconds of waiting it shows **Waiting for Kiln…** and what Kiln is busy with. A render error shows a message instead of a blank window.
- **Git no longer freezes the app.** Commits, pushes, fetches, pulls and status checks run in the background with time limits, never wait on a credential prompt, and stop the whole process tree when they give up. Starring, saving or moving a draft no longer runs git at all; publishing a change runs a fraction of the git commands it used to. Pulls, merges and syncs no longer hold up opening items.
- **Requests can't hang.** Every request has a time limit, the background worker restarts itself if it crashes, and simple reads (opening an item, the library, search, installs) no longer wait behind slower work. A lock left by a crash no longer stops Kiln from starting.
- **Faster library and installs.** Record folders, revisions and installed-copy states are cached and only re-read when they change, also across restarts, so opening Kiln, opening an item and coming back to the window do far less disk work. Installed copies are found with one folder listing per location, and a linked copy pointing into a project with `node_modules` is no longer walked. The app only re-checks installs when something changed.
- **Agent runs.** Starting a run no longer checks every agent CLI's version first. The runs list sends summaries instead of every step of every past run, progress is saved at most once a second, old run records are archived, and a CLI whose helper process keeps running can be cancelled.
- **Windows line endings.** A library checked out with Git for Windows' `autocrlf` no longer turns every item into a new draft, and Kiln keeps library files LF in its own checkout.
- **A lighter interface.** Dates in the library are formatted with cached formatters (they were most of the time spent drawing the list), rows and derived lists are memoised, typing in search no longer redraws everything, and focus, sync and publishing trigger one reload instead of bursts.

If you're on 0.20.0 or later with Windows, the AppImage or the .deb, Kiln offers this update itself. On macOS and the tar.gz it links to this page. The `latest*.yml` files are the update feeds the app reads; you don't need to download them.

Validation: the type check and 430 unit tests (429 passed, one skipped) passed locally on Linux, and the built app was opened against the real backend with the seeded demo library. Timings were measured on Linux with synthetic libraries of about 400 items; Windows figures in the investigation were estimates, not measurements.
