# Kiln 0.22.0

Ten improvements to everyday use, each behind its own switch in **Settings → Experimental features** so you can try them one at a time. They all start off, apply straight away without a restart, and only affect the machine you turn them on on. With every switch off, Kiln works as it did in 0.21.1. The [user guide](../GUIDE.md#experimental-features) describes each one in full.

- **Update installed copies.** A copy Kiln installed that is behind the approved version now says **Update** instead of "Installed". Update it from its location button, or all of them with **Update installs (N)** or **Approve & update installs** in the item header. Copies edited outside Kiln are never overwritten.
- **Keep changes made outside Kiln.** When a skill was edited in its folder, **Keep these changes** saves that copy as a new draft of the same item, and approving it takes the folder over as it is instead of rewriting it.
- **Code editor.** Items and config files open in a real editor with line numbers, highlighting, find and replace, and Ctrl+S. SKILL.md is checked as you type, bundled text files can be edited in Kiln, and title, tags and the other fields are kept until you save.
- **Background sync with GitHub.** Kiln checks GitHub every few minutes and shows **N new on GitHub · Pull** in the top bar. Pull and Merge work while you have drafts of other items, moving and reordering approved items is pushed on its own, and taking an approved side of a conflict keeps it approved.
- **Improve and re-test from experiments.** Trials are grouped by revision. A result offers **Improve with agent** (the chat opens with the result typed in), **Re-test current revision**, **Mark as passed / failed** and **Approve this revision**. The Test dialog can run an older revision, and experiments get 15 minutes.
- **Run notifications and runs list.** A desktop notification when a run finishes while Kiln is in the background, a toast with **Open result** when it is in front, a list of every run from the top bar, and a third run waits its turn instead of being refused.
- **Steadier, ranked search.** No more empty flash while typing. Results are ranked by relevance, forgive typos and follow renames. Quick search copies on a fast Enter, confirms the copy, hides when you click away and runs commands after `>`.
- **Docked chat with history.** Ask the agent opens beside the item, keeps each item's conversations across restarts, formats replies, shows what the agent changed with **View changes** and **Undo change**, and asks for agent access once per session.
- **Keyboard navigation and undo.** Home, End, Page keys, Shift-selection, Enter and type-ahead in the list, arrow keys in menus, a **?** shortcut sheet, **Ctrl+Z** for trash, moves, status and favourites, and dragging items onto collections.
- **Install into project folders.** **Install into project…** puts a skill into any project's `.agents/skills`, `.claude/skills` or `.github/skills` from its Installs tab, with one list of known projects that the Test dialog shares.

Also in this release, whatever the switches say:

- **Asking the agent can edit items on macOS and Linux.** The chat agent was given a Windows `kiln.cmd` batch file on every platform, which the shells Codex and Claude Code use on macOS and Linux cannot run, so the agent could not save changes through Kiln's CLI there. Those platforms now get a shell script.
- **The activity log names the agent that ran an experiment.** Claude Code experiments were recorded as "Codex assessment"; new ones say "Claude Code assessment". Older entries are left as they were.
- **The search index gained a description column.** It is a local cache that Kiln rebuilds when it starts, so nothing needs doing; an older version opening the same library still works.

Known limitations of the experiments are listed with each one in the guide. A few worth knowing before you try them:

- With **Background sync** on, the names of all your collections are published with organisation changes, including collections that so far hold only drafts.
- With **Keyboard navigation and undo** on, actions taken from the item pane (its star, Library actions, Restore) are not undoable yet; actions from the list and its menus are. Cmd+Z on macOS has not been tried on a real Mac.
- With **Improve and re-test** on, your own verdicts are stored as manual trials, so they show as "Manual" experiments if you turn the switch off again.

If you're on 0.20.0 or later with Windows, the AppImage or the .deb, Kiln offers this update itself. On macOS and the tar.gz it links to this page. The `latest*.yml` files are the update feeds the app reads; you don't need to download them.

Validation: before tagging, the type check and 246 unit tests (245 passed, one skipped) passed on Linux, and the Electron desktop suite had 52 passed and 3 skipped. One flag-off keyboard test timed out once during a full run, with a menu closing before the click landed; it passed eight times in a row on its own. CI passed on Windows and Linux. Each experiment has its own unit tests and a desktop test that runs it with its switch on and checks that nothing changes with it off; the existing tests pass unchanged. A packaged public Linux build started under the smoke check, and with every switch on it opened the code editor, the docked chat and the Settings switches without errors. The release workflow builds each platform on GitHub's runners and starts each packaged app once. Only Linux was used by hand; the Windows and macOS builds have not been tried with the switches on.
