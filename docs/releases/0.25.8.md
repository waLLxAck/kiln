# Kiln 0.25.8

Update agent defaults, simplify Settings, and install or update the official coding CLIs from Kiln.

- **New Codex defaults.** GPT‑6.1 Sol with `xhigh` reasoning for agent work; GPT‑6 Luna with `low` reasoning for CLI commit messages. Previous default model settings migrate once; custom selections remain saved.
- **Dark by default.** New preferences and the startup window use dark mode. Existing saved theme choices remain available.
- **YouTube profiles on this machine.** Browser and profile selectors list existing profile folders, including supported Snap and Flatpak locations. Cookie contents are read only by yt-dlp when fetching captions.
- **Install and update official agents.** Settings → Official agents offers native installation for missing Codex and Claude Code CLIs, checks for newer versions, and refreshes detection after installation. Downloads run only when you click Install or Update. Sign in through the official client after installing.
- **Cleaner Settings.** Official agents show their version without the executable path. The “Draft paths on this machine” section has been removed.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
