# Kiln 0.17.0

Safer publishing, private conversations, and clearer video collections.

- Publishing commits the exact approved revision, leaving newer drafts unpublished. Sync installs an existing approved revision and never creates an approval.
- Before agent interactions, a consent warning explains how Kiln uses your installed CLI, its file and command access, provider account usage, and the limits of its instructions. Choose **Agree and continue**, optionally **Don’t show again**; restore warnings in Settings.
- Raw agent sessions remain in machine-private storage. Sharing a conversation requires an explicit export. Library exports exclude private session attachments and machine provenance.
- **New session** starts a fresh chat. Switching items also starts a new session, without resuming a video's distillation conversation.
- Interrupted saves recover a complete revision, including metadata and attachments.
- Repository validation supports agent items. Description edits create new revisions while existing revision hashes remain readable.
- YouTube collections use the normalized video title instead of a generated topic, with a video ID added only to distinguish collisions.
- Fixed deleting experiments while another operation is finishing.

Older session-bearing revisions are archived locally and their current content becomes a cleaned, unapproved draft. Previously published Git history is not rewritten. Arbitrary secrets in user-authored content still require review before sharing.

Install the Windows setup executable, or use **Prepare update → Restart to update** when the installer is in your configured local update folder. Windows builds remain unsigned; the full Windows release matrix has not been certified.
