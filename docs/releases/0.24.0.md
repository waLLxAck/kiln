# Kiln 0.24.0

See how much every new agent session spends on your skills before it starts, and cut it with one click. The [user guide](../GUIDE.md) describes everything in full.

- **Who can invoke a skill.** A new **Invoked by** switch in the library (and on Machines and the item page) chooses between **Model & you** and **You only**. You only means the model can't pick the skill by itself, so its description no longer takes up context at session start, but you can still run it whenever you want. The switch edits the skill's own files in a fixed way: it adds or removes `disable-model-invocation: true` in SKILL.md (read by Claude Code, Copilot CLI and VS Code) and `policy: allow_implicit_invocation: false` in `agents/openai.yaml` (read by Codex), and leaves every other byte as it was. When the only change from an approved revision is that flag, Kiln approves the new revision itself (marked as Kiln's, carried from yours), publishes it, and updates the copies it installed; copies edited outside Kiln are skipped and named. On a newer draft it edits the draft and leaves approval to you. `is:model-invoked` and `is:user-only` filter the library, and Machines has a matching chip. The item page shows the front-matter row as "Model can invoke: no (you only)". [How each client reads the flag](../SKILL_INVOCATION.md), with sources.
- **Session start meter.** The status bar shows roughly how many tokens each harness gets before you type anything: **Session start · Claude ≈ … · Codex ≈ … · Copilot ≈ …**. Open it for the breakdown per harness, optionally for a project: the descriptions of skills the model can invoke (each with the same switch, so you watch the number drop), instruction files (CLAUDE.md, AGENTS.md), SessionStart hooks, MCP servers, and what can't be sized from here. Numbers are estimates from the text's length. The system prompt, hook output and MCP tool definitions aren't counted: their sizes aren't published, and Kiln never runs your hooks.
- **Resizable library columns.** Drag the edge between two column headings to resize; double-click it to fit the column to its content; right-click for **Reset width** or **Reset columns**. Edges can be moved from the keyboard too. Widths are kept per machine with the column order, and any column except Title can now be hidden from the header menu.
- **Filter Machines by state.** The legend is now a row of chips: **Installed**, **Changed outside Kiln**, **Outdated**, **Not managed**, **Not installed**, **Can't install** and **Model can invoke**, each with its count, plus **All** and **Needs attention** (changed, outdated or not managed). Click one or more to show only those skills; other cells fade. Filter by name, show Personal or Projects columns, and pick skills or agents. The filter is remembered.

Also in this release:

- Approvals can record `carriedFrom`, the approval they were carried over from. Older versions of Kiln ignore the field.
- A skill with the `disable-model-invocation` key can't be uploaded to claude.ai as it is, because claude.ai rejects unknown front-matter keys; the guide says so.
