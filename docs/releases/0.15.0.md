# Kiln 0.15.0

Seven improvements to everyday use:

- Read formatted Markdown, including headings, lists, links, tables and code. Switch to **Raw text** when needed; Copy still preserves the original text.
- Return to your Library tab, collection, search, filters, selection and scroll position after switching sections or reopening Kiln. Each Library view remembers its own state.
- Find the right action first: **Copy** for prompts, **Open link** for links, **Open file** for files, and **Approve & install** for draft skills with configured locations. Other actions live under **More**.
- See a short approval and installation status. Expand it for test, approval and GitHub details; pending edits and sync failures stay visible.
- Capture with **Save only** when you just want to keep something. **Analyze and add** still runs the agent. Save only also preserves attachments and does not fetch video captions.
- Preview content in Quick search, then use **Open item** or **Ctrl+Enter** to inspect it in the Library. **Enter** still copies.
- Undo an archive for eight seconds. The countdown pauses while the toast is hovered or keyboard-focused.

Install the Windows setup executable below, or use Kiln's **Prepare update → Restart to update** flow when this release is available in the configured local update folder.
