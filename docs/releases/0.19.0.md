# Kiln 0.19.0

A smoother first run and bulk cleanup in the library.

- **Imports during setup show up straight away.** Before, setup could import your skills and the library would still show zero until you restarted Kiln. The library now refreshes after each import and before setup finishes. An older refresh can no longer overwrite newer data, and stale filters are reset.
- **Setup covers more of your machine.** Onboarding lets you choose providers and folders, and it can import your native agent definitions in bulk. When it's done, there's a direct path to reviewing the library.
- **Skills are found in nested folders** and in the homes and projects you've configured. Agent discovery also covers your configured personal homes.
- **Bulk cleanup.** **Select all**, then trash, restore, delete permanently, archive or remove local copies in one go. Importing always leaves your original files where they are. Moving library items to the trash keeps their installed local copies.
- **No more ghost tabs.** A remembered tab with nothing in it, such as Skills (0) in a collection that only holds agents, now falls back to All.

The macOS and Linux builds are still new and untested on real machines. See the [install notes](../GUIDE.md#installing) for Gatekeeper on macOS and the AppImage sandbox on Linux. The Windows build is unsigned, so SmartScreen may warn before it runs.

Validation: the type check and unit tests passed on GitHub Actions Windows, Ubuntu and macOS runners. The Electron desktop suite passed on Ubuntu under xvfb, including new tests for importing during onboarding without a reload, stale collection tabs, bulk removal and collection deletion. The release workflow built and started each packaged app. Kiln was not tested by hand on a real Windows, Mac or Linux desktop.
