# Kiln 0.25.2

Find the material you use most and open a library reliably after an update.

- **One-click sorting.** Recently added, Last used, Most used and Title A–Z sit above the library list. Usage sorts show dates or counts beside the titles; never-used items stay at the end of Last used. Inside a collection, usage sorts follow activity across every item.
- **Clickable filters.** Choose Type, Status, Installed, Tags and other properties from Filters, with matching counts. Adding a filter preserves your search text, and keyboard filter shortcuts still work.
- **Clearer grouping.** Group by Collection, Type, Status or Last used. The activity groups separate today, yesterday, earlier activity and never-used items. Expand or collapse every group at once; each library view remembers its own grouping.
- **Saved views remember the whole view.** See the [user guide](../GUIDE.md#library-query-bar-and-collections) for saving and restoring views, including older filter-only views.
- **Reliable startup.** Kiln waits for the library to open before starting ordinary read deadlines. A slow first launch shows what is happening and continues automatically; an opening that does not finish offers Retry. Agent detection errors appear in Settings instead of replacing the startup error.
- **Stronger release checks.** Packaged apps must reach the usable setup screen and read their library before the release smoke test passes.

Usage ordering uses activity already recorded by Kiln. It does not trigger another scan of your files or external agent sessions.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64). Windows, AppImage and .deb installations offer this update in the app; macOS and tar.gz installations link to the downloads.
