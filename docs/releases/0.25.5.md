# Kiln 0.25.5

Fix publishing reviewed entries from Windows checkouts, and show approval status accurately while a GitHub push is pending or has failed.

- **Publish from Windows checkouts.** Git's automatic LF/CRLF conversion no longer makes Kiln's generated repository infrastructure look locally modified. Approving an entry can publish it without the false "Review locally modified repository infrastructure before publishing" error.
- **Keep real infrastructure changes protected.** Actual edits still require review. Publishing uses canonical LF text without rewriting your working files or introducing line-ending churn.
- **Show when an approval is on GitHub.** Entry, library and history badges distinguish publishing, failed publication and local-only review from a successfully published approval. A failed push keeps your review saved so publication can be retried without approving again.

After updating, retry publication for any entries blocked by the line-ending error.

Available for Windows (x64), macOS (Apple silicon and Intel), and Linux (x64).
